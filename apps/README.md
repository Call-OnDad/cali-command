# Cali Standalone Department Suites (`apps/`)

Independent, native programs designed for each Cali department. Each application runs completely decoupled from the central Cali Chat Server so that modifying, testing, or updating one module never resets or restarts the rest of Cali.

---

## Suite Directory

### 1. 🎬 Cali Video Studio (`apps/cali-video-studio`)
- **Port:** `http://127.0.0.1:8790`
- **Launcher:** [`Launch-Studio.cmd`](file:///d:/The%20Cali%20Project/apps/cali-video-studio/Launch-Studio.cmd)
- **Engines:** Local Piper neural TTS, FFmpeg fast CPU encoding (`-preset veryfast`), Google Colab GPU batch manifest exporter, 7 locked canonical mascot voices.
- **Features:** Descript-style script editor, draggable multi-track timeline dock, 9:16 Shorts & 16:9 HD WYSIWYG monitor, automated video maker, and locked canonical voice vault.

### 2. 🔍 Cali SEO & Search Radar (`apps/cali-seo-radar`)

  - *Dynamic custom domain registration on demand.*

### 3. 📱 Cali Social Media & Publishing Hub (`apps/cali-social-hub`)
- **Port:** `http://127.0.0.1:8793`
